# About
Halo, aku adalah seorang **Frontend Developer** yang sudah mulai berkarir sejak 2023,
aku senang membuat website menggunakan framework JavaScript seperti Svelte, React, dan Vue.
Dalam pengembangan website, aku lebih suka menggunakan bahasa atau library yang
type-safe khususnya TypeScript, saat ini aku hanya menggunakan Svelte untuk case tertentu
saja contohnya di project pribadi, lalu React dan Vue untuk di pekerjaan.

Tak hanya Frontend, aku juga hobi dalam **Reverse Engineering** terutama game yang
menggunakan Unity engine, **Reverse Engineering** yang aku lakukan seperti dumping
game data dan game network sniffing dengan teknik Protobuf reflection.
